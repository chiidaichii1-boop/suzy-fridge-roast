## Entry

`main.py` (Python 3 stdlib only) writes a single original line roasting
a fridge to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output/entry.txt`).

> My fridge's light only turns on to judge me at 2 a.m., then goes dark like it never saw the cake I definitely didn't eat.

The roast targets a specific, recognisable detail — the fridge light that
only ever switches on for a midnight snack raid — and turns on a twist in
the last few words: the light, the only witness, pretends it saw nothing.

## Run

```sh
python3 main.py
```

Deterministic: every run writes the exact same bytes.
